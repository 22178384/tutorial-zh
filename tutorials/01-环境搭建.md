# 01 环境搭建

这一篇的目标：让你有一个能写代码、能跑代码、能看日志的环境。

## 1. 终端

Linux/macOS 自带终端够用。macOS 我推荐 iTerm2，Windows 用 WSL2 + Windows Terminal。

常用到吐的几个命令，不熟的话先背下来：

```bash
pwd              # 我在哪个目录
ls -la           # 列出所有文件，包括隐藏的
cd /path/to/dir  # 进目录
cd ..            # 上一级
cd ~             # 回 home
cat file.txt     # 看文件内容
less file.txt    # 分页看，按 q 退出（大文件用这个，别用 cat）
grep -rn "关键字" .   # 递归搜索
```

`less` 里：`/` 搜索，`n` 下一个，`g` 回开头，`G` 到结尾，`q` 退出。这几个够用了。

**一个坑**：`ls -l` 看到的文件大小对目录来说没意义（那是目录项的大小，不是里面
文件总和）。想看目录占多少用 `du -sh 目录名`。

## 2. 装 Python

macOS 自带的 Python 是系统用的，别去动它。用 Homebrew 装：

```bash
brew install python@3.11
```

Ubuntu：

```bash
sudo apt update
sudo apt install -y python3.11 python3.11-venv python3-pip
```

验证：

```bash
python3.11 --version
# Python 3.11.x
```

**坑**：Ubuntu 上 `python` 这个命令可能不存在，只有 `python3`。别去建软链接指向
`python`，有些系统脚本依赖 `python` 不存在这个事实。

## 3. 虚拟环境（必做）

我见过太多人所有项目共用一个全局 Python，然后 A 项目的库版本把 B 项目搞崩。每个
项目一个虚拟环境，这是底线。

```bash
cd my-project
python3.11 -m venv .venv
source .venv/bin/activate        # macOS/Linux
# Windows PowerShell: .venv\Scripts\Activate.ps1
```

激活后命令行前面会有 `(.venv)` 提示。然后：

```bash
pip install requests
pip freeze > requirements.txt
```

**坑一**：`pip freeze` 会把所有依赖（包括依赖的依赖）都写进去。小项目无所谓，
正经项目用 `pip-tools` 或者 `poetry` 管理。

**坑二**：`.venv` 目录**千万不要提交到 git**。里面路径是绝对路径，你提交了别人
也用不了。`.gitignore` 里加一行 `.venv/`。

**坑三**：忘记激活虚拟环境，`pip install` 就装到全局去了。症状是"我明明装了怎么
还 ModuleNotFoundError"。看一眼命令行前面有没有 `(.venv)`，或者：

```bash
which python
# 应该指向 .venv/bin/python，不是 /usr/bin/python
```

## 4. 编辑器

我用 VS Code，配这几个扩展就够：

- Python（微软官方那个）
- Ruff（格式化 + lint，比 black + flake8 快得多）
- GitLens（看每行谁改的）

在项目根目录建一个 `.vscode/settings.json`：

```json
{
  "python.defaultInterpreterPath": ".venv/bin/python",
  "editor.formatOnSave": true,
  "[python]": {
    "editor.defaultFormatter": "charliermarsh.ruff"
  }
}
```

**坑**：VS Code 右下角能选解释器，如果代码里 import 报红线，八成是选错解释器了，
点右下角切到 `.venv`。

## 5. 配好之后的样子

一个干净的项目目录大概长这样：

```
my-project/
├── .venv/              # 不提交
├── .gitignore
├── requirements.txt
├── README.md
└── src/
    └── main.py
```

`.gitignore` 最小版本：

```
.venv/
__pycache__/
*.pyc
.env
.DS_Store
```

最后跑一下确认：

```bash
source .venv/bin/activate
python -c "import sys; print(sys.executable)"
pip list
```

`sys.executable` 应该指向 `.venv` 里的 python。指向别的地方就是没激活成功。
